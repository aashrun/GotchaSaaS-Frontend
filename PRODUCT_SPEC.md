# Product experience

Gotcha! uses neutral black/white themes and Arial, with the original Classic Quality wordmark, pastel primary actions, borderless controls and glass surfaces. New Project contains a personalized greeting and a compact idea composer over orbital Earth imagery in dark mode or clouds in light mode. Images rotate automatically every two hours and at login. Credits and account controls stay pinned in the collapsible sidebar. Projects, optional folders, search and Recents provide navigation; Manage groups billing, members and settings.

Sending an idea saves a project and transforms the existing workspace into a neutral chat. A verified account with configured models/sandbox starts a bounded build directly, within server-enforced credit and spending limits. Missing setup or insufficient credits appear in the conversation with the prompt saved. There is no separate canvas workbench or starter browser that could be mistaken for a generated app.

The agent reads and edits supported project source, researches through guarded tools, switches server-approved specialists, checks the build and backend, and tests browser behaviour. Real actions produce concise, pulsing progress updates. Questions open from chat: blocking questions pause a checkpoint; non-blocking questions defer specified source paths while independent work continues. Answers return to the agent context. The preview opens beside chat after current source passes its checks. Code, checkpoints, test evidence, memory, export and optional reviewed GitHub actions are in Project tools.

The supported full-stack starter includes Express/PostgreSQL authentication, persistent records and cross-user authorization inside an isolated E2B sandbox. The preview frame uses an authenticated request broker; backend interaction requires an explicit five-minute preview lease. These capabilities have prior recorded live verification, plus automated fixtures. They do not establish that an arbitrary generated CRM is production ready. A complete production deployment, production data migration and ongoing app hosting remain separate work.

Unavailable or planned capabilities include arbitrary dependencies/runtimes, generic binary uploads with quarantine/antivirus, visual element editing, automatic GitHub App synchronization, customer-owned provider accounts/BYOK, production custom domains, analytics/hosting/database metering, full commercial plans, advanced monitoring and marketplace. Connected customer OAuth/document/messaging actions are a clearly labeled roadmap. Public privacy/terms pages remain drafts. No security certification or unlimited capability claim is made.
