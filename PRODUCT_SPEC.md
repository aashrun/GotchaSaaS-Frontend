# Product scope and acceptance

Nebula Studio uses IFB-style neutral black and white themes, Arial typography, restrained glossy mint-to-blue primary actions, reduced-motion handling, responsive navigation, and a resizable/collapsible chat-and-preview studio with optional source tools. The workspace background is a close-up orbital Earth view, with the planet continuing outside the frame. The dark gallery contains 22 macOS Earth wallpaper video frames; light mode uses two original blue-sky and white-cloud images. Scenes advance at login, every two hours. The sidebar's account/theme footer stays inside the viewport while navigation scrolls independently. There is no workspace top navbar.

The implemented local user path is: register/login → project home with a single idea composer → open the saved idea in left-side chat with a live preview beside it → inspect and edit source → lock files → create/compare/restore checkpoints → export ZIP → review actual credit ledger. Folders and recent projects appear in the left sidebar. Projects can be moved between folders, searched, renamed, archived and duplicated. Deleting a folder preserves its projects. Project creation requires no naming dialog; the first line of the idea becomes an editable project title. An empty app starter is available. Team roles and administration are enforced server-side. Login uses a still Earth/sky image, without video.

The configured AI path is implemented but has no live provider verification yet: automatically prepare first estimate when configured → approve estimate → durable job → source snapshot → structured generation → E2B build → bounded repair → safe source apply → isolated compiled preview → usage settlement. OpenRouter joins OpenAI, Anthropic and Gemini as an available model transport. UI separates built artifacts from the original curated template and separates build pass from functional verification.

The required full CRM acceptance in the master brief is NOT satisfied: generated server authentication, customer database connectivity/migrations/CRUD/authorization and full-stack Cloudflare publication still need implementation and live verification. The frontend CRM starter deliberately labels its session-only data and does not claim production login or persistence.

Other unavailable features are labeled or feature-disabled: visual element editing, image/vision uploads, true browser bug verification, custom domains, GitHub App synchronization, customer-owned provider accounts/BYOK, analytics/hosting/database metering, platform API keys, advanced monitoring, full plan catalog, support/abuse workflows, ten full templates and marketplace.

Public privacy/terms pages are drafts for legal review. No customer testimonials, final pricing, production deployments, or security certifications are invented.
