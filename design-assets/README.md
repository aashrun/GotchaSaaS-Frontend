# Original planetary login artwork (superseded)

The current interface and media use the Earth collection described in [Earth background notes](EARTH_BACKGROUNDS.md). The earlier ringed-planet source below is retained as a design artifact; its runtime poster/video were replaced by Earth imagery.

The IFB Job Portal login is the layout reference: a 44/56 split, full-height visual panel with bottom-aligned copy, and a centered authentication form. Only this app was edited.

The source artwork in `planetary-login.png` was generated with the built-in image_gen tool. No CLI image-generation fallback was used.

Final generation prompt:

> Use case: stylized-concept. Asset type: cinematic background for the left 44% panel of a SaaS login screen, portrait 1024x1536. Create an elegant realistic 3D astronomical vista: a large ringed planet hanging in deep navy space, softly illuminated lavender and icy mint atmospheric edge, fine detailed silver rings crossing diagonally. Planet centered in upper half, occupies about 65% of width, lower third mostly empty dark space for overlaid interface copy. Tiny sparse stars and a distant small moon, refined photographic science-fiction mood with restrained haze, rich blacks, physical texture, restrained pastel rim light. Existing product palette deep navy #0b0d1f, lavender #c4b5fd, mint #99f6e4, off-white. No text, letters, logos, interface, spacecraft, people, cartoon style, decorative UI panels, or watermark. High detail, cinematic composition, premium minimal atmosphere.

The old runtime video and poster have been deleted. Login now uses a static Earth or sky image from the current collection. This earlier source is retained only as a superseded design artifact.
